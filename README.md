# Online-Courses

> ITI Project

## Overview
Online-Courses is a web-based application designed to provide a seamless experience for browsing, exploring, and enrolling in online courses. Developed as part of the ITI (Information Technology Institute) project, this repository showcases best practices in front-end development using JavaScript, CSS, and HTML.

## Features

- **Course Catalog**: Browse a comprehensive list of available online courses.
- **Course Details**: View detailed information for each course, including syllabus, instructor, and enrolment options.
- **Responsive UI**: Designed to look great on both desktop and mobile devices.
- **Interactive Elements**: Dynamic content and user interactions powered by JavaScript.
- **Modern Styling**: Clean and attractive interface utilizing CSS.

## Technology Stack

- **JavaScript** (67.3%): Controls application logic, dynamic content, and interactivity.
- **CSS** (32.1%): Styles the application for a responsive and polished look.
- **HTML** (0.6%): Defines the structure of web pages.

## Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/Mohamed-Taha69/Online-Courses-.git
   ```
2. **Navigate to the project directory**
   ```bash
   cd Online-Courses-
   ```
3. **Open `index.html` in your browser to view the application**
